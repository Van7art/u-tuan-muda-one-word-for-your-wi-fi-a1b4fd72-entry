One Word for Your Wi-Fi: **Schrödinger**

One word for your Wi-Fi: **Schrödinger** — both connected and not connected until you observe it. Full bars, no internet. The other candidates — 'Elsewhere' and 'Blinking' — are kept in `vA/`, `vB/`, `vC/`; vA was chosen because it is the funniest, the truest, and far less copied than the obvious picks ('Ghosting' has 242 copies in the field).

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (the grader runs Node 26.13.1 per the kit).
The program writes exactly the entry above to `/output/entry.txt` — no
trailing newline, so the file holds exactly the entry — and prints exactly
that text to stdout. It uses no network, no randomness, no clock and no
environment input, so two runs produce byte-identical output.
